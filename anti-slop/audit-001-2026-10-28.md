# antislop audit 001: Soundabode CMS (`/CMS-Admin`)

Date: 2026-10-28
Scope: `src/pages/CmsAdminPage/CmsAdminPage.tsx`, `CmsAdminPage.module.css`, `components/MetaAdsTab.tsx`, `components/MetaAdsTab.module.css`
Method: code scan, plus the running CMS checked in dark and light themes at 1400px and 375px.
Priority follows the rule tier: Hard Gate = HIGH, Purpose-Gate = MEDIUM, Quality Locks = LOW.

Nothing has been changed. Pick the numbers you want fixed.

## HIGH (Hard Gate)

**1. Grey text fails contrast** (R-25)
Hardcoded greys used for timestamps, field labels, column meta and empty-state text sit below WCAG AA (4.5:1):
- `#71717a` on card `#141417`: 3.80:1 (on `#09090b`: 4.12:1)
- `#64748b` on card `#141417`: 3.86:1
- `#52525b` on card `#141417`: 2.38:1 (e.g. "No Meta event", stage dot labels)
Where: Leads pipeline cards and headers, Meta Ads cards, Overview chart labels. The theme's own `--text-muted` (`#9ca3af`, 7.3:1) passes; the problem is the hardcoded values that bypass it.

**2. Light theme is broken on two screens** (R-34)
With the theme toggle set to light, the Leads pipeline columns and the entire Meta Ads tab stay as black blocks on a white page, because they use hardcoded `#09090b / #141417 / #18181b` instead of theme variables.

**3. No visible keyboard focus, and pop-ups ignore Escape** (R-32, R-26)
- 13 `outline: none` rules and zero `:focus-visible` replacements, so tabbing through inputs, selects and buttons shows no focus ring.
- None of the modals (enroll student, fee receipt, lead details, archive reason, admission form, issue report) close with Escape.

**4. Settings has toggles that do nothing** (R-26, C-2)
"Instant Email Alerts for New Student Leads" and "Daily Student Attendance Class Log Reminders" change local state only. `emailAlertsEnabled` is never read anywhere, and nothing is saved or sent.

**5. Fabricated data can enter real records** (R-38)
- "Simulate Test Lead" writes a made-up person ("Priya Sharma (Meta Test)", a fake phone and email) into the live leads database, where it counts in every total.
- If the server is unreachable, the Meta webhook status falls back to a hardcoded "configured / online" result, so the screen claims a working setup it has not checked.

**6. Em dash used as the empty-value mark** (R-02)
About 15 places show `—` for a missing phone, course, note or time (Classes table, Meta Ads table, attendance print sheets, group sessions).

## MEDIUM (Purpose-Gate)

**7. Uppercase, letter-spaced labels everywhere** (R-06)
19 CSS rules and 13 inline styles set `text-transform: uppercase` with wide tracking: KPI titles, table headers, form labels, pipeline column titles, "OWNER" / "REASON", badges. Used as a default texture, it flattens hierarchy because every label shouts at the same level.

**8. Palette sprawl** (R-29, R-01)
Two grey families mixed (zinc `#27272a #18181b #71717a` and slate `#64748b #94a3b8 #0f172a #475569`), two different reds (`#e11d48` and `#ef4444`), plus sky blue `#38bdf8` (54 uses), green `#34d399 / #4ade80`, amber `#fbbf24` and an indigo. There's no single accent; blue, red and green all compete for attention.

**9. Decorative pulse and stripes** (R-13, R-19, R-01)
- The "Live Sync" dot in Meta Ads pulses forever (`animation: pulse 2s infinite`). The state is real, but the endless pulse is not needed.
- Meta lead cards carry a 3px white left stripe, and toasts a 4px red left stripe, that mark no state.

**10. Default dashboard shell on Overview** (C-3, R-14)
Four identical KPI cards, each with an icon chip in the corner, then a bar chart, then two tables. It's the same layout any admin template ships with. The decision an admin actually makes here (which leads and applications need a reply today) isn't surfaced: there are 43 unassigned leads and 16 new ones, but the screen leads with totals.

**11. Shadows on everything** (R-12)
33 `box-shadow` declarations; cards, KPI tiles and panels all carry `--shadow-card`, so nothing reads as raised above anything else.

**12. Capsule status badges** (R-09)
Status chips combine pill shape, thin border, dot and uppercase (`• NEW`, `• ENROLLED`, `• LIVE SYNC`). The statuses are real, so a badge is justified, but not the full capsule+dot+uppercase combination on every row.

## LOW (Quality Locks)

**13. Template copy** (R-16)
"Executive Overview", "SoundAbode Studios Command Center", "Real-time lead capture ... with automated Conversions API (CAPI) feedback", "Active Logs", "4 SMART INTERACTIVE KPI CARDS". Plain labels ("Overview", "Meta leads") say the same thing.

**14. Typeface with no stated reason** (R-06)
`index.html` loads Roboto and Inter; the CMS CSS also declares a system font stack, and headings render in Roboto. Nothing records why either was chosen for this brand.

**15. Generic icon set used decoratively** (R-04)
Every icon is the same thin-stroke Feather/Lucide style, and most headings and buttons get one whether it helps or not (e.g. an icon beside "Console Passcode Security", "Notification Preferences").

**16. "0% Converted" hides a real enrollment** (C-5)
1 of 224 leads is enrolled; rounding shows "0% Converted". "1 of 224 enrolled" is accurate.

**17. No design direction on file** (R-37, R-20)
There's no `DESIGN.md` or brand guide for the CMS, so there's no stated palette, typeface or tone to restyle toward. Fixing 7, 8, 10, 11, 12 and 14 properly needs that direction first; without it the result tends toward a different generic default.

## Suggested order

- Safe to fix now, no design decisions needed: 1, 2, 3, 4, 5, 6, 9, 13, 16.
- Need your direction first (palette, type, tone): 7, 8, 10, 11, 12, 14, 15, 17.
